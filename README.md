# hello-github

## What this is

This repository contains a single static `index.html` page that serves as a
simple introduction to Git and GitHub.

## Viewing the page locally

There is no build step and no dependencies. Either:

- Open `index.html` directly in a browser (double-click it, or run
  `open index.html` on macOS / `xdg-open index.html` on Linux), or
- Serve it with any static file server, e.g. `python3 -m http.server`, and
  visit `http://localhost:8000`.
